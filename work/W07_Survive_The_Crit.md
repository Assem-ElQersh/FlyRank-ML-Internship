# W07 Survive the Crit: Portfolio Revisions

## 1. The Design Critique (Senior Reviewer Feedback)

**The 10-Second Test:**
- **What do you do?** You are a Deep Learning & AI Engineer bridging research and production. 
- **Do I believe you are good at it?** Mostly, due to the sheer breadth of the projects, but execution gaps on the portfolio reduced immediate trust.

**Raw Feedback:**
1. **Missing Project Images:** Projects 2 and 3 have no images, making the grid look broken or unfinished.
2. **Vaporware Links:** The GitHub links for MedFlow-V2 and RepoDigest point to the main GitHub profile, not the actual repos, making them look like vaporware.
3. **Corporate Speak:** "I build intelligent solutions with AI & DL" is generic and doesn't stand out.
4. **Missing CV/Resume:** No quick way to download a resume for recruiters.
5. **No Live Demos:** Only source code links, no live apps to play with.

---

## 2. Sorting the Feedback

**Must-Fix (Addressed Immediately):**
- **Vaporware Links:** Pointing to the root profile is a huge red flag. Updated links directly to `Assem-ElQersh/MedFlow-V2` and `Assem-ElQersh/repodigest`.
- **Missing Project Images:** Added premium tech/medical placeholder images to the missing project cards to fix the broken grid layout.
- **Corporate Speak:** Changed the hero text to a stronger hook: *"I engineer production-ready AI models... bridging the gap between academic research and reality."*
- **Missing CV:** Added a "Download CV" button directly in the hero section alongside GitHub and LinkedIn.

**Nice-to-Have (Deferred):**
- **Live Demos:** Setting up live hosting for complex FastAPI/PyTorch projects takes significant time/money. A screen recording or well-documented GitHub README is a sufficient workaround for now.

---

## 3. Evidence of Must-Fixes

The following changes were deployed to the live site:
- **Hero Update:** Stronger value proposition and added `Download CV` button.
- **Project Grid:** Sourced and inserted contextually relevant imagery for MedFlow-V2 (Medical/Healthcare) and RepoDigest (Code/Data).
- **Direct Linking:** All project links now resolve exactly to their specific GitHub repository rather than the root profile, instantly verifying the proof of work.
